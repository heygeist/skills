# HeyGeist Caption Contract

Default to checking the user's supplied copy, not rewriting it.

## Voice

- Write Thai-first conversational copy using `เรา` when a rewrite is requested.
- Sound warm, practical, and lightly playful rather than corporate or boastful.
- Explain specialized terms before relying on them.
- Prefer concrete situations and plain-language examples.

## Facebook formatting

- Use short mobile-friendly paragraphs.
- Use a standalone `.` line between sections when following the established HeyGeist Facebook format.
- Keep official product, Skill, command, and file names exact.
- Avoid Markdown that will display literally.
- End with one low-friction CTA when the post needs a response.

## Report

- Unsupported performance, quality, or time-saving claims
- Better/worse framing unsupported by the source
- Terms used before they are explained
- A caption hook that repeats the image verbatim
- A claim contradicted by the image
- Missing honest limitations when they materially affect the story

Save supplied copy verbatim. Offer a rewrite only when asked.
