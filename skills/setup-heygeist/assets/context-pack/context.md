# HeyGeist Product Context

Use this vocabulary and product framing in HeyGeist social work. Read workspace `DESIGN.md` for every visual-identity decision and `caption.md` for copy voice. Verify feature-specific claims against the supplied source or current product code.

## Product language

- **Agent Skill:** a reusable instruction package installed in a compatible AI agent. Avoid calling it a magic prompt or built-in feature.
- **Agent App:** a supported coding-agent product such as Codex, Claude Code, or Cursor.
- **Agent Stream:** the current or recent activity HeyGeist tracks for one coding-agent workflow. Avoid using session when the product concept is specifically Agent Stream.
- **Agent Stream Label:** the short human-readable name identifying an Agent Stream.
- **Pet Roam:** a Pet display strategy where visible Agent Streams receive separate always-on-top Pet homes along the desktop edge. Avoid reducing it to a widget or dashboard card.
- **Running:** an Agent Stream actively working.
- **Waiting:** an Agent Stream requesting permission, approval, or user input. Avoid paused or idle when the product state is Waiting.
- **wait-what:** a communication-reset command asking an agent to re-pitch its latest message with needed context and simpler technical English. Avoid describing it as retry or start over.
- **Feature Story:** a cohesive product narrative expressed through related social, visual, and video assets.
- **Export:** an approved publish-ready deliverable.
- **Working Artifact:** a temporary candidate, preview, prototype, or cache. Never call one final.

## Accuracy

- Explain coding-agent concepts for readers who may not write code.
- Prefer concrete situations to abstract feature claims.
- Do not invent performance, quality, or time-saving claims.
- Do not imply that documentation replaces testing and review.
- Keep unfamiliar internal terminology out of the image; explain it in the caption.
