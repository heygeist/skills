# HeyGeist Visual Contract

Use this as a brand layer over the generic `social-image` layout grammar. It is not a fixed post template.

## Brand behavior

- Use white as the primary canvas.
- Use Ink for primary type and Mango as the active signal.
- Use Sky for illustration or secondary comparison roles, not as default decoration.
- Use warm hairlines for depth rather than warm filled backgrounds.
- Use Figtree for Latin and Noto Sans Thai for Thai when approved font files are installed; otherwise use the configured fallbacks.
- Use the canonical wordmark and Crownheart files unchanged when installed.
- Never redraw, recolor, trace, or generate the wordmark or mascot.

## Headline

- Make the headline a reaction rather than a product title.
- Prefer spoken Thai, one or two intentional lines, warm and a little teasing.
- Let the subhead explain what the headline reacts to.
- Keep each line below the generic renderer's 92% wrap-risk threshold.

## Provenance labels

Map the generic values to HeyGeist labels:

- `real`: `REAL …`, naming the source only when it truly produced the capture
- `example`: `ตัวอย่าง · EXAMPLE`
- `generated`: `ภาพประกอบ AI · AI ILLUSTRATION`

Treat `REAL` over a mock or generated image as a release blocker.

## Optional assets

The pack manifest may contain approved paths for:

- `logo`
- `mascot`
- `font_display`
- `font_body`

If an asset is missing, omit it or use a plain text brand label. Do not fabricate a substitute.
